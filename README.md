Entry for "The Funniest Office Joke, Judged Head to Head" on make.fun.

`main.ts` (Node) writes one single-line office joke to `/output/entry.txt` —
no trailing newline, fully deterministic, no network, no clock, no random
input. The joke: a printer that only jams on deadline day gets promoted to
management, because it already knows how to stop all work.
